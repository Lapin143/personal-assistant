# Ассистент

Семейное приложение: финансы, цели, вишлист, напоминания, авто, дом, документы, здоровье, люди.
Работает как статический сайт (без сервера), как и приложение «Меню» в ветке `main`.

## Как открыть

Чтобы открыть приложение в браузере:
Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`. Адрес: https://lapin143.github.io/personal-assistant/

## Данные

- Данные хранятся в браузере (localStorage). Стартовый шаблон — `data.json`.
- Перенос между устройствами: Люди → Данные → Экспорт / Импорт.
- **Важно:** репозиторий публичный. Не коммитьте выгрузку с финансами в этот репозиторий.
  Для уведомлений Telegram файл `data.json` должен содержать актуальные события, поэтому
  пока придётся выбирать между приватностью и автоматическими напоминаниями. Вопрос решим позже.

## Уведомления в Telegram (бесплатно, через GitHub Actions)

1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. Напишите своему новому боту любое сообщение. Узнайте свой chat id, например через @userinfobot.
3. В репозитории: Settings → Secrets and variables → Actions → добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — ваш chat id
4. Проверьте запуск: Actions → «Напоминания в Telegram» → Run workflow.

Расписание — ежедневно в 06:00 по Москве. Сообщение уходит, только если есть события
в пределах «Дней заранее» из настроек.

## Уведомления в браузере

Кнопка «Включить уведомления» на главной. Работают, пока приложение открыто.

## Разделение прав

Выбор «Кто вы» скрывает личные операции других участников. Это только удобство интерфейса:
все данные лежат в браузере и в файле. Настоящая защита будет отдельной задачей.

## Файлы

- `core.js` — расчёты (ближайшие события, сводка месяца, расход топлива, цели, долги). Без DOM, его же использует скрипт уведомлений.
- `app.js` — интерфейс.
- `scripts/notify.mjs` — отправка напоминаний в Telegram.
- `.github/workflows/notify.yml` — расписание.
