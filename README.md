# Ассистент

Семейное приложение: финансы, цели, вишлист, напоминания, авто, дом, документы, здоровье, люди.
Работает как статический сайт (без сервера). Тестовая версия.

## Как открыть

Settings → Pages → Source: Deploy from a branch → `main`, папка `/ (root)`.
Адрес: https://lapin143.github.io/personal-assistant/

## Данные

- Данные хранятся в браузере (localStorage). Стартовый шаблон — `data.json`.
- Перенос между устройствами: Люди → Данные → Экспорт / Импорт.
- **Важно:** репозиторий публичный. Для теста данные в `data.json` не важны, но не коммитьте
  туда реальные финансы. Безопасное хранение решим отдельно.

## Напоминания

Вверху любого раздела показывается блок «Скоро» с событиями в пределах
«Дней заранее» (настройка в разделе «Люди»). Скрыть до завтра можно кнопкой ✕.

## Разделение прав

Выбор «Кто вы» скрывает личные операции других участников. Это только удобство интерфейса:
все данные лежат в браузере и в файле. Настоящая защита будет отдельной задачей.

## Файлы

- `core.js` — расчёты (ближайшие события, сводка месяца, расход топлива, цели, долги). Без DOM.
- `app.js` — интерфейс.
- `index.html`, `style.css` — разметка и стили.
- `data.json` — стартовые данные.
